# The BYOW logo

A paper bag with a wallet dropped in it: bring your own. `scripts/build-logo.mjs` draws every file here.
Change the script and run `node scripts/build-logo.mjs`; never edit an SVG by hand.

| File | Use it for |
|---|---|
| `byow-logo.svg`, `byow-logo-dark.svg` | The mark with the word, on a light or a dark background. |
| `byow-mark.svg` | The mark alone, in one colour, from 32px up. Inline, it takes the text colour (`currentColor`), so it sits on any button; as an `<img>` it is black. |
| `byow-mark-small.svg` | The same at 24px and under: fewer, deeper teeth, a wider gap, no dot. |
| `byow-mark-color.svg`, `byow-mark-color-dark.svg` | The mark in colour, on a light or a dark background. |
| `byow-wordmark.svg` | The word alone, in one colour. |
| `social-preview.png` | GitHub's social preview (the repository's Settings, then Social preview), 1280×640. |

Colours: kraft `#c4925a` for the bag, ink `#16181d`, paper `#f5f2ea`. The bag stays kraft; the wallet in it
can be any colour, a wallet's own for instance.
